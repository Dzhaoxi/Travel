# 沿途景点小程序

极简的微信小程序：输入起终点 + 交通方式，查询沿途可下车游览的景点。

## ✨ 特性

- 🚆 **三种交通方式**：驾车、公交（含火车）、步行
- 🗺️ **沿线城市自动识别**：从路径规划中提取途经城市
- 📍 **景点动态查询**：基于高德 POI API，无需预置数据
- ⭐ **本地收藏**：用 `wx.setStorage` 存储，无需登录
- 🔗 **一键唤起地图**：点击"去这里"跳转高德地图

## 🚀 快速开始

### 1. 准备工作

- 注册微信小程序账号，获取 **AppID**（个人订阅号也可）
- 注册高德开放平台账号，申请 **Web API Key**（勾选"微信小程序"）
  - https://lbs.amap.com/dev/key/app

### 2. 配置

打开 `app.js`，修改：

```js
globalData: {
  amapKey: '你的高德 Key',  // 替换此处
}
```

打开 `project.config.json`，修改：

```json
{
  "appid": "你的小程序 AppID"
}
```

### 3. 运行

用**微信开发者工具**打开本项目目录：

1. 工具 → 导入项目
2. 项目目录：选择 `Travel/` 根目录
3. AppID：填入你的（无 AppID 可选"测试号"）
4. 点击"导入"

## 🛠 路线解析策略

`utils/route.js` 中的 `getWaypointCities` 采用**双策略**：

1. **已知路线优先**（快）：内置 `COMMON_CITIES` 表，覆盖黑龙江常见线路
   - 哈尔滨 ↔ 漠河
   - 哈尔滨 ↔ 牡丹江
   - 哈尔滨 ↔ 佳木斯
   - 哈尔滨 ↔ 黑河
2. **高德路径规划 + 逆地理编码**（兜底）：调用 API 解析 polyline 坐标串

新增路线时，往 `COMMON_CITIES` 加一行即可：

```js
'哈尔滨-五大连池': ['哈尔滨', '北安', '五大连池']
```
